# 📊 2026年5月第3周综合报告（5月12-18日）

> 报告周期：2026年5月12日至5月18日

## 一、政治动态

### 1.1 征兵法修订草案推进

柬埔寨政府持续推进《征兵法》修订工作。该草案于2025年首次提出，旨在加强国防力量建设，主要内容包括：

- **服役期限调整**：将现行的18个月服役期延长至24个月
- **服役年龄范围**：扩大至18-30岁男性公民
- **豁免条款缩减**：减少部分职业群体的豁免资格
- **处罚力度加强**：对逃避兵役者加大罚款和行政处罚力度

政府表示，该修订案是应对地区安全形势变化的必要举措，旨在提升柬埔寨国防能力。

### 1.2 地方政府换届进展

- **省级理事会选举**：5省已完成新一届省级理事会组建工作
- **市长选举**：金边市、暹粒省等主要城市完成市长换届
- **基层治理调整**：多个县镇启动基层行政人员轮岗

## 二、经济贸易

### 2.1 对外贸易数据（前4月累计）

根据柬埔寨海关总署数据，2026年1-4月主要贸易指标如下：

| 指标 | 数值 | 同比变化 |
|------|------|----------|
| 外贸总额 | 约185亿美元 | +12.3% |
| 出口额 | 约78亿美元 | +15.1% |
| 进口额 | 约107亿美元 | +10.2% |
| 贸易逆差 | 约29亿美元 | - |

**主要贸易伙伴占比**：
- 🇺🇸 美国：约35%（最大出口市场）
- 🇨🇳 中国：约25%（最大进口来源）
- 🇪🇺 欧盟：约12%
- 🇻🇳 越南：约8%
- 🇹🇭 泰国：约6%

### 2.2 中柬双边贸易

2026年1-4月中柬贸易持续增长：

- **贸易总额**：约46亿美元，同比增长约18%
- **柬对华出口**：约12亿美元（主要为农产品、纺织品）
- **柬自华进口**：约34亿美元（主要为机械设备、电子产品、原材料）

### 2.3 外国直接投资

- **批准投资项目**：约120个
- **协议投资总额**：约25亿美元
- **主要投资来源**：中国、日本、韩国、新加坡
- **投资主要集中在**：制造业、房地产、能源

### 2.4 经济增长预期

世界银行及亚洲开发银行调整柬埔寨2026年经济增长预期：

| 机构 | 预测值 | 调整方向 |
|------|--------|----------|
| 世界银行 | 5.5% | ↓下调0.3% |
| 亚开行 | 5.8% | ↓下调0.2% |
| 柬埔寨政府 | 6.2% | 维持预期 |

下调原因：全球需求疲软、制衣业面临竞争压力、房地产市场调整持续。

## 三、基础设施

### 3.1 西哈努克港扩建工程

柬埔寨最大的深水港——西哈努克港扩建工程正式启动：

- **项目投资**：约15亿美元
- **投资方**：中国路桥工程有限责任公司（CRBC）
- **建设内容**：
  - 新建3个深水集装箱码头泊位
  - 疏浚航道以容纳更大船舶
  - 建设物流仓储设施
  - 升级港口管理系统
- **预期效益**：港口年吞吐量将从目前约100万标箱提升至300万标箱
- **工期**：预计2028年完工

### 3.2 金边-巴域高速公路

金边至巴域（柬越边境）高速公路建设持续推进：

- **全长**：约135公里
- **投资方**：中国路桥（采用BOT模式）
- **建设进度**：路基工程完成约40%
- **预计完工**：2027年

2026年5月的佛诞节（国际佛教日）庆祝活动在柬埔寨各地盛大举行：

**金边主会场活动**：

- 呼吁社会和谐、团结互助
- 重视佛教对道德建设的积极作用
