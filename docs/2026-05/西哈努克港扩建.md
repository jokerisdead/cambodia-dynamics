# 🏗️ 西哈努克港扩建工程

---

## 一、项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 项目名称 | 西哈努克港深水码头扩建项目 |
| 柬埔寨名称 | គម្រោងពង្រីកកំពង់ផែស្ថានីយ៍ព្រៃសេរី |
| 港口名称 | 西哈努克自治港（Sihanoukville Autonomous Port） |
| 港口代码 | KOSIHAN |
| 地理位置 | 柬埔寨西南部西哈努克省 |

---

## 二、项目背景

### 2.1 现有港口概况

| 指标 | 现有数据 |
|------|----------|
| 运营年份 | 1960年开始运营 |
| 年货物吞吐量 | 约100万TEU（集装箱） |
| 码头泊位 | 3个集装箱泊位 + 2个多用途泊位 |
| 最大吃水深度 | 约9米 |
| 堆场面积 | 约30万平方米 |

### 2.2 扩建必要性

1. **需求增长**
   - 柬埔寨对外贸易持续增长
   - 港口吞吐量年均增长约10%
   - 现有设施趋于饱和

2. **竞争压力**
   - 区域内港口竞争加剧
   - 越南岘港、泰国林查班港扩建
   - 需要提升竞争力

3. **战略地位**
   - 作为"一带一路"重要节点
   - 打造东南亚物流枢纽
   - 服务中柬双边贸易

---

## 三、项目详情

### 3.1 投资情况

| 项目 | 详情 |
|------|------|
| 总投资额 | 约15亿美元 |
| 投资方 | 中国路桥工程有限责任公司（CRBC） |
| 合作模式 | BOT（建设-运营-移交） |
| 运营期限 | 约50年 |

### 3.2 建设内容

**码头设施**：

| 建设内容 | 规模 | 说明 |
|----------|------|------|
| 新建集装箱泊位 | 3个 | 每个泊位长400米 |
| 水深 | 14.5米 | 可停靠大型集装箱船 |
| 疏浚工程 | 约1000万立方米 | 航道和港池浚深 |

**配套设施**：

| 设施类型 | 建设规模 |
|----------|----------|
| 集装箱堆场 | 新增约50万平方米 |
| 冷藏集装箱区 | 约1万平方米 |
| 仓库设施 | 约5万平方米 |
| 港口管理系统 | 智能化升级 |
| 疏港道路 | 约5公里 |

### 3.3 建设进度安排

| 阶段 | 时间 | 主要工作 |
|------|------|----------|
| 一期 | 2026-2027年 | 第一个新泊位建成 |
| 二期 | 2027-2028年 | 第二、三个泊位建成 |
| 三期 | 2028年 | 配套设施完善 |
| 完工 | 2028年 | 全面投入运营 |

## 四、预期效益

### 4.1 经济效益

| 效益指标 | 预期提升 |
|----------|----------|
| 年货物吞吐量 | 从100万TEU提升至300万TEU |
| 年营业收入 | 预计增长约3倍 |
| 创造就业 | 直接就业约5000人 |
| 带动投资 | 吸引临港产业投资约20亿美元 |

### 4.2 战略效益

1. **区域物流枢纽**：打造东南亚地区重要物流中心
2. **贸易便利化**：降低物流成本，提升贸易效率
3. **产业带动**：促进西哈努克经济特区发展
4. **互联互通**：强化中柬"一带一路"合作

---

## 五、项目进展

### 5.1 最新动态

**2026年5月12日**：
- 西哈努克港扩建工程启动仪式举行
- 柬埔寨首相、中国驻柬大使出席仪式
- 首期工程正式破土动工

### 5.2 当前工程状态

- **现场准备**：完成施工营地建设
- **设备调运**：主要施工设备陆续到位
- **人员部署**：中柬双方施工团队组建完成
- **海底清淤**：疏浚作业准备启动

## 七、相关配套设施

### 7.1 交通衔接

- **高速公路**：金边-西哈努克高速已建成通车
- **铁路规划**：规划建设西哈努克-金边铁路连接
- **机场**：西哈努克机场开通多条国际航线

### 7.2 产业园区

- **西哈努克经济特区**：已入驻企业160余家
- **深水码头后方**：规划建设物流园区
- **临港工业区**：发展出口加工业

---

## 八、面临的挑战

1. **资金筹集**：项目融资规模大
2. **技术难度**：深海疏浚工程技术要求高
3. **环境保护**：需要做好海洋生态保护
4. **运营管理**：提升港口运营效率
