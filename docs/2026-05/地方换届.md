# 🏛️ 地方换届进展

---

## 一、选举制度概述

### 1.1 柬埔寨地方治理结构

| 层级 | 名称 | 民选官员 |
|------|------|----------|
| 省级 | 省理事会 | 省长、副省长 |
| 市级 | 市理事会 | 市长、副市长 |
| 县级 | 县理事会 | 县长时间 |
| 区级 | 区理事会 | 区长时间 |
| 乡/村 | 基层行政 | 乡长、村长 |

### 1.2 地方选举周期

- **省级理事会选举**：每5年一次
- **市/县级理事会选举**：每5年一次
- **区级选举**：每5年一次
- **乡/村级选举**：每5年一次

- 邀请国际观察员

- 新旧班子做好工作交接
- 重点项目持续推进
- 民生政策无缝衔接

## 五、换届工作特点

### 5.1 年轻化趋势

本轮换届呈现年轻化特点：
- 新任省级领导平均年龄下降
- 增加技术型干部比重
- 注重基层工作经验

### 5.2 女性参政

- 女性领导干部比例有所提升
- 多个省份配备女性副职
- 促进性别平等参与

### 5.3 专业化导向

- 重视经济管理经验
- 加强城市管理能力
- 注重环境保护意识
