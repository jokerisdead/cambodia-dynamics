# 📖 关于网站

---

## 网站简介

本资料库由九江学院柬埔寨研究中心建设维护，旨在为区域国别研究提供柬埔寨相关信息的追踪与汇集服务。

---

## 建设宗旨

- **客观呈现**：严格遵循事实导向，呈现原始信息
- **持续追踪**：定期更新，保持时效性
- **系统整理**：分类清晰，便于检索
- **学术参考**：服务区域国别研究需要

---

## 内容范围

### 覆盖领域

| 类别 | 主要内容 |
|------|----------|
| 🏛️ 政治动态 | 政府政策、法律法规、地方治理 |
| 📈 经济贸易 | 贸易数据、投资动态、产业发展 |
| 🙏 宗教文化 | 佛教活动、传统文化、节庆民俗 |
| 🏗️ 基础设施 | 交通基建、能源设施、城市建设 |
| 🌐 外交关系 | 双边关系、国际合作、东盟事务 |
| 🛡️ 国防安全 | 军事合作、边境安全、反恐动态 |
| 📚 教育科研 | 高等教育、学术交流、科研成果 |
| 🌍 国际组织 | 联合国、东盟、世行等国际组织 |

### 时间跨度

持续追踪柬埔寨各领域动态，重点关注近期发展，兼顾历史背景。

---

## 使用说明

### 访问方式

1. 进入网站需输入访问密码
2. 侧边栏可按月份浏览内容
3. 顶部搜索框可检索关键词
4. 点击页面标题可跳转相关分类

### 内容更新

- **常规更新**：每周六定期更新
- **重大事件**：随时增补
- **数据更新**：以实际公布时间为准
