# 🙏 国际佛教日庆祝活动（2026年5月）

---

## 一、节日概述

### 基本信息

| 项目 | 内容 |
|------|------|
| 节日名称 | 国际佛教日（Vesak Day） |
| 柬埔寨名称 | ទិវាបុណ្យវប្បធម៌អន្តរជាតិ |
| 庆祝日期 | 2026年5月 |
| 宗教意义 | 纪念佛陀诞生、成道、涅槃 |
| 参与人数 | 全国约200万人次 |

---

## 二、活动安排

### 2.1 金边主会场活动

**地点**：乌廊山（Mountain Kulen）、皇宫广场、主要佛寺

**主要活动日程**：

| 时间 | 活动内容 |
|------|----------|
| 清晨 | 佛教徒前往佛寺礼佛 |
| 上午 | 僧侣诵经祈福仪式 |
| 中午 | 传统布施活动 |
| 下午 | 佛学讲座与研讨会 |
| 傍晚 | 万灯供佛法会 |
| 夜间 | 传统文艺表演 |

### 2.2 全国各省市活动

- **暹粒省**：吴哥窟周边佛寺举行庆祝仪式
- **马德望省**：传统舞蹈表演与布道活动
- **磅湛省**：湄公河畔放生活动
- **各省市**：点亮佛灯祈福仪式

---

## 三、官方庆祝活动详情

### 3.1 开幕仪式

- **时间**：5月某日
- **地点**：金边市某重要佛寺
- **出席人员**：
  - 柬埔寨国王或代表
  - 宗教大臣
  - 佛教界高僧
  - 各国外交使节
- **主要内容**：
  - 国王/代表致辞
  - 高僧诵经祈福
  - 点灯仪式

### 3.2 文化展示

- **传统舞蹈**：高棉传统舞蹈表演
- **佛事展览**：佛教艺术与文化展览
- **素食推广**：免费素食斋饭供应
- **慈善活动**：向贫困群体捐赠物资

## 五、政府致辞要点

### 5.1 宗教事务意义

- 强调佛教在柬埔寨历史与文化中的核心地位
- 肯定佛教对社会道德建设的积极作用
- 呼吁民众践行佛教慈悲理念

### 5.2 社会发展期望

- 倡导社会和谐、民族团结
- 鼓励青年一代传承佛教文化
- 强调宗教在促进和平发展中的作用
